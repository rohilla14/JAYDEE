# Owner Dashboard

Vite + React + TypeScript app for shop owners (reports, products, staff).

See the monorepo [README](../README.md) for full setup.

```bash
cp .env.example .env
npm install
npm run dev -- --host 0.0.0.0 --port 5175
```

Open http://127.0.0.1:5175 and log in with an **owner** account.
